# Sprachraum

A local app for learning German from scratch. Reviews, stories written for your level, podcasts, AI conversation and tutor lessons (via Granola) all share one database, so what happens in one feeds the others.

Run `./run`, which starts the server and opens http://localhost:8790.

The Chrome extension in `extension/` adds clickable German subtitles to YouTube and Netflix. Load it from `chrome://extensions` → Developer mode → Load unpacked.
